# FocusAI

Бесплатное веб-приложение для студентов: чек-ин за 1 минуту по 7 сферам дня, тест внимания за 90 секунд (Focus Score) и личные инсайты о том, что связано с вашей концентрацией. Дерево растёт от регулярности, а советы в библиотеке опираются на источники.

**Приватность:** нет аккаунтов и сервера. Все данные хранятся только в браузере (IndexedDB), их можно выгрузить в JSON или удалить в настройках.
Не является медицинской консультацией.

## Запуск локально
```bash
npm install
npm run dev          # http://localhost:3000
```

## Проверки
```bash
npm run typecheck && npm run lint && npm test   # логика и компоненты (Vitest)
npx playwright install chromium                  # один раз
npm run e2e                                      # сборка + smoke-тест на 375px
```

## Демо для презентации
Настройки → «Показать демо-данные». Загружается пример за 21 день (только в пустое приложение). Везде видна плашка «демо-данные», убрать их можно там же.

## Бесплатный деплой
`npm run build` создаёт статический сайт в папке `out/`.
- **Vercel:** импортировать репозиторий на vercel.com, Framework: Next.js. Сборка идёт без настроек.
- **Любой статический хостинг** (Netlify, Cloudflare Pages): загрузить папку `out/`.

## Стек
Next.js (static export) · TypeScript · Tailwind CSS · Dexie · Recharts · Vitest · Playwright. Подробности: `docs/PRODUCT.md`, `docs/CONTEXT.md`.
