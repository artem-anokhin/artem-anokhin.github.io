# FocusAI

Сайт: https://artem-anokhin.github.io

Делаю небольшое приложение для студентов, чтобы разобраться, что на самом деле мешает сосредоточиться. Сон, кофе, телефон, стресс или всё вместе. Идея простая: каждый день минута на отметки, а через неделю видно, что у тебя связано с хорошими и плохими днями.

Что там есть:
- чек-ин за минуту по 7 пунктам: сон, еда, кофе и вода, настроение, спорт, учёба, отдых
- тест реакции на 90 секунд (Focus Score) и пара мини-тестов: «Цвет и слово», «Запомни порядок»
- таймер для учёбы на 15/25/50 минут с тёмным экраном
- привычки (до 5 штук), цели с планом «если — то», заметки, отсчёт до экзаменов
- после 7 дней появляются инсайты и итоги недели
- дерево, которое растёт, пока ты пользуешься приложением, и награды за это
- светлая и тёмная тема, можно добавить на главный экран телефона, работает без интернета

**Про данные.** Регистрации и сервера нет. Всё хранится только у тебя в браузере (IndexedDB), никуда не отправляется. В настройках можно выгрузить данные в JSON или удалить всё одной кнопкой. Если почистить данные браузера, всё пропадёт, имейте в виду.

Это не медицинская консультация, просто инструмент, чтобы лучше понимать себя.

## Если хочешь потестить

Открой ссылку выше с телефона и пользуйся хотя бы неделю: инсайты появляются только на 7-й день. Потом напиши мне, что понравилось, что бесит, где непонятно. Любой фидбек полезен, особенно критика.

Хочешь просто посмотреть, как всё выглядит? В настройках есть «Показать демо-данные». Это пример за 21 день, его потом можно убрать там же.

## Запуск у себя

```bash
npm install
npm run dev    # http://localhost:3000
```

Проверки:
```bash
npm run typecheck && npm run lint && npm test
npx playwright install chromium   # один раз
npm run e2e
```

`npm run build` собирает статический сайт в `out/`. Деплой на GitHub Pages идёт автоматически при пуше в main (`.github/workflows/pages.yml`).

## Стек

Next.js (static export), TypeScript, Tailwind, Dexie, Recharts, Vitest, Playwright.
