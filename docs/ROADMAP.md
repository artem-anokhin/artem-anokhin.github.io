# FocusAI — дорожная карта (от MVP к Google Play)

Цель: качественный продукт, который команда улучшает годами, с сильной базой студентов.
Главный принцип не меняется: **данные только у пользователя**. Это наше отличие от трекеров, а не ограничение.

## Что решает судьбу продукта
1. **Удержание** — человек возвращается каждый день. Главный рычаг: напоминание в его время.
2. **Доверие** — приватность, честные формулировки, источники. Уже есть, бережём.
3. **Ценность к 7-му дню** — первые инсайты. Всё до 7-го дня должно вести к ним.
4. **Язык** — казахский + русский. Для вузов и грантов Казахстана это обязательно.

## Ключевое техническое решение: Capacitor, а не просто сайт
Тот же код (Next.js static export) упаковываем в Android-приложение через **Capacitor**.
- Локальные напоминания без сервера (`@capacitor/local-notifications`) — главный рычаг удержания, приватность сохраняется.
- Нормальное «Поделиться» (картинка недели в сторис).
- Данные хранятся в приложении, а не в браузере, который может их очистить.
- Сайт и Telegram Mini App продолжают работать из того же кода.
Альтернатива — TWA (обёртка над сайтом): проще, но без локальных уведомлений. Не берём.

## Этапы

### Фаза 0 — Фундамент (2 недели)
- GitHub-репозиторий, ветки и PR, CI (GitHub Actions: typecheck, lint, тесты, e2e) — чтобы команда могла работать вместе, не ломая продукт.
- Деплой на Vercel, Telegram Mini App (`docs/TELEGRAM.md`).
- **Импорт данных** из JSON (экспорт уже есть) — перенос на новый телефон без аккаунтов.
- Страница «Политика конфиденциальности» (обязательна для Google Play и для доверия).
- Пилот 20–30 человек (`docs/GROWTH.md`), опрос на 7-й и 14-й день.

### Фаза 1 — Удержание и качество (1–2 месяца)
- Напоминание о чек-ине в выбранное время (сначала в Android-приложении, в Telegram — позже).
- «Итоги недели» по воскресеньям: что изменилось, какой эксперимент попробовать.
- Казахский язык (i18n), доступность (экранные дикторы, крупный шрифт).
- Улучшения по отзывам пилота; поправить подписи, которые ждут решения Лейлы.

### Фаза 2 — Google Play (2–4 месяца)
- Android-сборка через Capacitor, иконки, скриншоты, описание на рус./каз.
- Аккаунт разработчика Google Play — разовый взнос ~25 $ (единственная обязательная трата).
- Для новых личных аккаунтов Google требует **закрытое тестирование: ≥12 тестировщиков 14 дней подряд** — участники пилота закрывают это требование. *Проверить актуальные правила перед подачей.*
- Анкета Data safety («данные не собираются и не передаются») и декларация для приложений о здоровье и благополучии.

### Фаза 3 — Рост и AI (после релиза)
- AI-слой (требование AI-Sana): «Ответ AI» с недельным разбором. Только по согласию, с пометкой «Ответ AI», без отправки заметок. Сначала исследовать варианты на устройстве.
- Партнёрства с вузами: психологические службы, студсоветы, амбассадоры на факультетах.
- Групповые челленджи (нужен минимальный сервер — отдельное решение команды, без личных данных).

## Как измерять без слежки
- Опросы по согласию (Google Forms) на 7-й и 14-й день.
- Установки и оценки в Google Play, посещения сайта (без cookies).
- Возможное решение: анонимный счётчик «был активен сегодня» без ID — только по явному согласию.

## Решения, которые принимает команда
| Вопрос | Рекомендация |
|---|---|
| Android: Capacitor или TWA | Capacitor |
| Аналитика | Только опросы и магазин до отдельного решения |
| Казахский язык | В фазе 1 |
| Сервер | Не раньше фазы 3, только для групп |
