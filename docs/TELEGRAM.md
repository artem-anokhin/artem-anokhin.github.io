# FocusAI в Telegram (Mini App, без сервера)

Решение: бот — это «обёртка» над тем же сайтом. Кнопка в боте открывает FocusAI внутри Telegram.
Сервер не нужен, данные по-прежнему хранятся только на устройстве (в браузере Telegram).

## Что нужно заранее
1. Задеплоенный сайт по HTTPS (Vercel), например `https://focusai.vercel.app`.

## Шаги в @BotFather (5 минут, делает владелец аккаунта)
1. `/newbot` → имя: `FocusAI — фокус для студентов` → username, например `focusai_kz_bot`.
2. `/setdescription` (текст до нажатия «Старт»):
   > Узнайте, что помогает вашей концентрации. Чек-ин за 1 минуту, тест внимания за 90 секунд, личные инсайты через 7 дней. Бесплатно, без регистрации, данные только на вашем телефоне. Не является медицинской консультацией.
3. `/setabouttext` (в профиле бота):
   > Фокус для студентов: 1 минута в день. Данные только у вас.
4. `/setuserpic` — логотип 512×512 (дерево на синем фоне).
5. `/mybots` → бот → **Bot Settings → Configure Mini App → Enable Mini App** → URL сайта.
   Тогда в профиле бота появится кнопка «Открыть».
6. `/mybots` → бот → **Bot Settings → Menu Button** → URL сайта, текст: `Открыть FocusAI`.

Ссылка для постов и QR-кодов: `https://t.me/<username>?startapp` (сразу открывает приложение).

## Что проверить после запуска (на Android и iPhone)
- Онбординг → чек-ин → закрыть Telegram → открыть снова: данные на месте.
  Риск: Telegram на некоторых телефонах может очистить данные встроенного браузера. Если так — советуем «Экспорт данных» и открывать сайт в браузере.
- «Поделиться неделей»: внутри Telegram системное меню может не открыться. Если картинка не сохраняется — следующий шаг: загрузка через Telegram `shareToStory` (нужна отдельная доработка).
- Вёрстка на 375px и кнопка «Назад».

## Почему без «умного» бота
Бот, который пишет напоминания или отвечает на сообщения, требует сервер и хранение chat_id — это персональные данные и уход от принципа «данные только на устройстве». Возможный следующий шаг: напоминания по подписке, только после пилота и отдельного решения команды.
