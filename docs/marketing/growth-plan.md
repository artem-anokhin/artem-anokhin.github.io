# FocusAI — план роста через TikTok / Reels / Shorts

## Позиционирование
**Бесплатная учебная помощница для студента: 90 секунд, и видно, какой у тебя сегодня фокус. Данные остаются в телефоне.**

## 3 сегмента
| Сегмент | Боль | Угол хука |
|---|---|---|
| **Медики** | Бесконечная зубрёжка, сессия, ночные смены | «Проверь реакцию после ночи над анатомией. 90 секунд» и «Запомни порядок»: сколько удержишь? |
| **IT** | Залипание в телефон, дедлайны, ночной код | Челлендж Focus Score, сессии 25/50 минут, секретные награды (сова, «42»: без спойлеров, «найди сам») |
| **Гуманитарии / юристы** | Много чтения, прокрастинация, экзамены | «Цвет и слово»: мозг спотыкается на ровном месте. Плюс отсчёт до экзамена и «Учиться вместе» с одногруппником |

Формат ролика: человек проходит тест на камеру → результат на экране → «а у тебя сколько?». Без лиц можно: запись экрана и голос.

## Воронка
1. **Ролик** (хук в первые 2 секунды: вызов, цифра своего результата, сравнение «до кофе / после пары»).
2. **Ссылка в профиле** → сразу на `/tests/` или `/test/` (не на главную). Отдельная ссылка на каждый сегмент (`?c=med`, `?c=it`, `?c=hum`), без личных данных.
3. **Первое действие:** пройти один мини-тест и увидеть результат. Онбординг и согласие короткие, одним экраном.
4. **Второе действие:** сохранить результат → первый чек-ин → дерево получило каплю.
5. **Приглашение друга:** «Учиться вместе» на сессию или карточка-история с результатом.

## Вирусные петли, которые продвигаем
- **«Учиться вместе»**: ссылка на общую сессию. Главная петля: друг приходит с готовым действием.
- **Карточка для сторис** (1080×1920): минуты фокуса. Вариант «побей мой результат» со ссылкой на тест.
- **Секретные награды**: повод для роликов «нашёл пасхалку» и для комментариев «как получить?».
- **Отсчёт до экзамена**: в сессию делимся в чате группы.
- **Сад**: еженедельный ролик «как выросло дерево за неделю» от команды.

## 5 метрик (без персональных данных)
Анонимная аналитика просмотров страниц (например, Vercel Analytics), никаких ID пользователей.
1. **Переходы по кампаниям**: просмотры страниц с `?c=…` по сегментам и роликам.
2. **Посетитель → тест**: доля просмотров страницы результата теста от просмотров входной страницы.
3. **Тест → онбординг завершён**: просмотры `/` после `/welcome/`.
4. **Приглашения**: просмотры ссылок «Учиться вместе» (вход по ссылке-приглашению).
5. **Возврат**: просмотры `/checkin/` к общему числу посетителей по неделям (грубый прокси удержания).

## График на 2 недели (1 ролик в день, 3 площадки одновременно)
| День | Неделя 1 | Неделя 2 |
|---|---|---|
| Пн | Медики: тест реакции после ночи | Повтор лучшего хука недели 1 |
| Вт | IT: челлендж Focus Score | Гуманитарии: «Учиться вместе» с другом |
| Ср | Гуманитарии: «Цвет и слово» | Медики: отсчёт до экзамена |
| Чт | Пасхалка-тизер (без спойлера) | IT: сессия 50 минут, таймлапс |
| Пт | «Запомни порядок»: челлендж в комментариях | Ролик из ответов на комментарии |
| Сб | Дерево за неделю | Дерево за 2 недели |
| Вс | Разбор: какой хук сработал (внутренний, не постим) | Итоги, решение по сегментам |

Правило: каждый ролик даёт ссылку на свой сегмент. Через 2 недели оставляем 2 лучших угла по метрике 2.

## Риски формулировок в рекламе
- **Не медицина.** Не пишем «улучшает память / лечит / диагностирует СДВГ, выгорание». Пишем «проверь», «посмотри свой результат», «отследи».
- **Связь, а не причина.** «Сон связан с твоим результатом», а не «недосып вызывает». Инсайты появляются только через 7 дней, в роликах это не обещаем «с первого дня».
- **Никакой выдуманной статистики.** Не пишем «90% студентов…» или «+30% к фокусу». Только реальные результаты автора ролика с пометкой «мой результат».
- **Шкалы тестов наши, не клинические.** Не говорим «норма», «IQ», «уровень мозга».
- **Демо-данные** в кадре подписываем «демо-данные».
- **AI.** Если в ролике текст, сгенерированный AI, помечаем «Ответ AI». Локальную статистику AI не называем.
- **Без фейковых дедлайнов** и «осталось N мест»: продукт бесплатный, давить нечем и незачем.
- В каждом ролике или в профиле: «Не является медицинской консультацией».
